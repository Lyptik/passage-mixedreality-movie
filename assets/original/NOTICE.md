# Original presentation assets

These browser assets were copied from the existing PASSAGE website at
https://www.passage-mixedreality.com/ to preserve its original presentation
during its owner's migration to GitHub Pages.

The HTML retains the original Slider Revolution 5.4.8.3 layer coordinates,
responsive breakpoints, keyframes, timings, navigation and slide transitions.
The Silverscreen base stylesheet supplies the original typography defaults.
Only browser assets are included; no WordPress backend or administration code
is required or included.

Existing copyright and license notices in vendor files continue to apply.
No new or unrestricted license is granted to Slider Revolution, Silverscreen,
or the film's photographs, artwork or other content. Font Awesome, jQuery,
Open Sans and Ubuntu Condensed retain their own licenses. Ubuntu's license
is in `fonts/Ubuntu-OFL.txt` (Ubuntu Font Licence); Open Sans's license is
in `../Open-Sans-OFL.txt`.

`css/static.css`, `js/prepare.js` and `js/static.js` provide the static shell,
keyboard access and the reduced-motion adaptation. They do not replace the
original animation definitions.
